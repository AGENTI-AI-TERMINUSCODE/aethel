# Aethel Integrations — Browser Extension MV3 & IDE MCP 1-Click

## 1. Chrome / Edge Sidebar Extension (Manifest V3)
1. Open `chrome://extensions` or `edge://extensions` and enable **Developer Mode**.
2. Click **Load unpacked** and select `integrations/browser-extension/` (or download directly from `https://aethel.terminuscode.com/downloads/aethel-browser-extension.zip`).

## 2. VS Code / Cursor / Claude Desktop (MCP 1-Click)
```bash
python integrations/ide-mcp/install_aethel_mcp.py
```
Connects directly to `https://aethel.terminuscode.com/mcp/sse`.
